# ✅ Quick Start Checklist - Executive Meeting Summary Generator

Print this checklist and check off each step as you complete it!

## 🎯 Before You Start
- [ ] I have a computer with internet connection
- [ ] I have about 30 minutes available
- [ ] I have a meeting transcript ready to test (.txt, .docx, or .pdf file)

## 🔑 Step 1: Get OpenAI API Key
- [ ] Created account at [platform.openai.com](https://platform.openai.com)
- [ ] Generated new API key
- [ ] Copied and saved the API key safely (starts with `sk-`)
- [ ] Added billing information to OpenAI account
- [ ] Set spending limit (recommended: $20/month)

## 💻 Step 2: Install Software
- [ ] Downloaded and installed Python from [python.org](https://python.org)
  - [ ] ✅ Checked "Add Python to PATH" during installation
- [ ] Downloaded and installed Node.js from [nodejs.org](https://nodejs.org)
  - [ ] ✅ Used the LTS version
- [ ] Tested installations:
  - [ ] `python --version` works
  - [ ] `node --version` works

## 📁 Step 3: Setup Application
- [ ] Downloaded all application files
- [ ] Created folder `ExecutiveSummaryApp` on Desktop
- [ ] Copied all files into this folder
- [ ] Found `.env.example` file
- [ ] Made copy and renamed to `.env`
- [ ] Opened `.env` file in text editor
- [ ] Replaced `your_openai_api_key_here` with my actual API key
- [ ] Saved the `.env` file

## 🔧 Step 4: Install Dependencies
- [ ] Opened Command Prompt (Windows) or Terminal (Mac)
- [ ] Navigated to app folder: `cd Desktop/ExecutiveSummaryApp`
- [ ] Ran command: `npm run install-all`
- [ ] Waited for installation to complete (5-10 minutes)
- [ ] No error messages appeared

## 🚀 Step 5: Start Application
- [ ] In same command prompt, ran: `npm run dev`
- [ ] Saw messages about servers starting
- [ ] Backend started on port 5000
- [ ] Frontend started on port 3000
- [ ] Opened browser to `http://localhost:3000`
- [ ] Saw the Executive Meeting Summary Generator interface

## 📝 Step 6: Test the Application
- [ ] Saw drag-and-drop upload area
- [ ] Uploaded a test transcript file
- [ ] File uploaded successfully (progress bar appeared)
- [ ] Processing completed (30-60 seconds)
- [ ] Summary appeared with structured sections
- [ ] Tested "Copy to Clipboard" button
- [ ] Tested "Export PDF" button
- [ ] Tested "Export DOCX" button

## ✅ Daily Usage Reminders
**To start the app each time:**
1. [ ] Open Command Prompt/Terminal
2. [ ] Navigate: `cd Desktop/ExecutiveSummaryApp`
3. [ ] Start: `npm run dev`
4. [ ] Open browser: `http://localhost:3000`

**To stop the app:**
1. [ ] Go to Command Prompt/Terminal
2. [ ] Press `Ctrl + C` (Windows) or `Cmd + C` (Mac)

## 🆘 If Something Goes Wrong
- [ ] Restarted computer and tried again
- [ ] Checked internet connection
- [ ] Verified OpenAI API key is correct
- [ ] Confirmed I have OpenAI credits available
- [ ] Tried with a smaller test file first

## 🎉 Success!
- [ ] Application is working correctly
- [ ] I can upload transcripts
- [ ] I can generate summaries
- [ ] I can export results
- [ ] I understand how to start/stop the app
