## 📋 Super Simple Setup (5 minutes total!)

### Step 1: Get Your OpenAI API Key (3 minutes)
1. Go to [https://platform.openai.com/api-keys](https://platform.openai.com/api-keys)
2. Sign up or log in
3. Click "Create new secret key"
4. Copy the key (starts with `sk-`)
5. Add billing info and set a $20/month limit

### Step 2: Download and Run (2 minutes)
1. Download the `ExecutiveSummaryGenerator.html` file
2. Double-click the file to open it in your browser
3. Enter your API key in the app
4. Start uploading transcripts!

## 🆘 Troubleshooting

### "Invalid API Key" Error
- Make sure your key starts with `sk-`
- Check you copied the complete key
- Verify your OpenAI account has billing set up

### "Quota Exceeded" Error
- Add credits to your OpenAI account
- Check your billing settings at platform.openai.com

### File Won't Upload
- Make sure it's a .txt file
- Check file size is under 10MB
- Try a smaller file first

### Summary Not Generating
- Check your internet connection
- Verify your API key is correct
- Make sure your transcript has readable content

## 💡 Pro Tips
